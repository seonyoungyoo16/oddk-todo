# oddk

Next.js + React로 만든 할 일·하루 계획 앱입니다. [배포 화면](https://seonyoungyoo16.github.io/oddk-todo/todo/)

오늘 / 이번 주 / 전체 할 일에서 같은 업무를 탐색하고 목록·시간표·목표로 연결합니다. 하루 계획에 ALPEN의 할 일·소요시간·여유·선택·점검을 통합했습니다.

## 실행과 검사

Node24.22.0 / npm11.19.1, 잠금 파일을 사용합니다.

~~~powershell
npm.cmd ci
npm.cmd run dev
# http://localhost:3000/todo
npm.cmd test
npm.cmd run lint
npm.cmd run typecheck
~~~

## 데이터와 사용 흐름

- 제목만으로 등록하고 항목을 눌러 날짜·시작/종료·여유·중요도·마감·분류·태그·목표를 정합니다. 제목120자·메모2000자, 여러 줄 자동 확장을 지원합니다.
- 한국 날짜 기준이며 날짜 없는 업무는 전체 할 일에 보관합니다. 오늘/주간·목록/시간표·목표가 같은 ID를 사용합니다.
- 수행 = 작업 + 포함된 여유. 수행2~240분, 여유1분 이상·수행 미만입니다. 자정을 넘는 일정은 각 날짜에 해당하는 구간을 나눠 합산합니다.
- 고정·휴식/숨긴 일정까지 충돌을 확인합니다. 계획 합계·중복 제거 점유·빈 시간은 서로 다른 값입니다.
- 목표는 최대32개 세부 목표와 연결한 업무를 표시합니다. 기존8×8 원본을 보관하고, 큰 업무를 실행 단계로 나눌 수 있습니다.
- 반복은 이번만/이후/전체 범위를 확인합니다. 알림은 사용자가 내 정보에서 켜며 지원 환경·권한·네트워크에 따라 전달이 달라집니다.
- 작업 시작·일시정지·휴식·종료와 수동 보정으로 실제 시간을 기록합니다. 계획 시간과 실제 기록은 별도로 비교합니다. 실제 기록도 별도 백업/가져오기를 제공합니다.
- 오늘의 남은 시간 재조정은 변경·유지·미배치 사유를 확인한 뒤 적용합니다. 고정·보호·완료·소요시간을 유지하고, 열린 실제 기록이 있으면 종료 후 진행합니다. 시각 복구안과 최근 변경 실행 취소를 제공합니다.

계획 형식은 V5, 반복·알림 사용 시 V6입니다. V1~V4는 원문 백업 후 이전하고 V6를 저장한 계정의 구형 쓰기는 거부합니다. 기존 날짜 없는 내용을 임의로 오늘에 넣지 않습니다.

비로그인 계획은 이 브라우저 localStorage, 실제 기록은 IndexedDB에 보관됩니다. 브라우저 저장소를 지우기 전에 각각 백업하세요. 초안·실행 취소·재조정 복구안은 해당 브라우저의 계정 범위별 보관이며 서버 동기화 대상이 아닙니다.

**Google·GitHub 로그인을 사용할 수 있습니다.** 로그인한 계정의 확정 계획·목표·실적은 다른 기기에서 이어서 사용할 수 있습니다. 다른 계정/비로그인 저장소는 분리하며 계정 전환 뒤 원래 계정으로 돌아오면 그 계정 초안을 복원합니다. 오프라인 확정 편집은 전송 대기 캐시에 보관합니다. 실제 OAuth·실물 기기 최종 인수는 사용자가 별도로 수행합니다.
