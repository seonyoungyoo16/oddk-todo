# 활동 시간과 일정 안내

활동 시간은 선택 날짜의 `availabilityByDate`에 사용자가 직접 저장한 값만 사용한다. 값이 없으면 `미설정`으로 표시하고 시작·종료 입력칸은 비운다. 활동 시간 밖/가용 시간 초과 안내와 자동 재조정에는 임의의 09:00–18:00 기준을 적용하지 않는다. 시간표의 00:00–24:00 좌표는 화면 표시와 실제 일정 겹침 계산에만 사용하며 설정값으로 저장하지 않는다.

- 하루계획 상단의 활동 시간 설정/변경 → 시작·종료 입력 → 저장. 선택 날짜에만 적용하며 고정·휴식, 다른 날짜, 기존 할 일을 보존한다.
- 종료 00:00은 해당 날짜의 24:00이다. 누락·역전 입력은 저장할 수 없다.
- 일정 안내를 X로 닫으면 같은 문제의 안내를 이 기기/계정 범위에 보관한다. 새로고침과 페이지 이동 후에도 다시 띄우지 않는다. 제목·정렬·문제 없는 일정 변경은 같은 문제로 취급한다. 문제 시각·충돌 상대·활동 구간 등 검사 내용이 달라지면 새 안내를 표시한다.
- 시간표 확인은 숨긴 필터를 풀고 문제 일정의 시각·사유를 표시한다. 시간표와 목록의 같은 일정에 테두리/배지를 표시하고 선택한 위치로 이동한다. 닫은 뒤에도 일정 점검 버튼으로 직접 확인할 수 있다.
