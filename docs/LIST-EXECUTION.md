# 하루 계획 목록에서 작업 실행

- 최신 로컬 UI에서는 대시보드의 작업 시작 목록과 수행 기록을 하루 계획의 할 일 목록으로 옮겼다. 대시보드의 다음 일정 영역은 제거하고 하루점검을 유지한다.
- 할 일 오른쪽의 작업 시작으로 실제 시간 기록을 시작한다. 실행 중인 항목은 기록 중으로 표시하고, 다른 작업 시작은 현재 기록이 끝날 때까지 비활성화한다. 완료한 항목과 요약 항목에는 시작 버튼을 표시하지 않는다.
- 수행 기록은 목록 상단에서 확인한다. 종료한 항목에는 최근 작업 시간과 휴식 시간을 표시하며, 종료 시각을 기준으로 계산해 새로고침 후 시간이 늘어나지 않는다.
- ALPEN의 계획한 작업·여유 시간 및 시간표 배치는 유지한다. 실제 작업·휴식 기록은 계획값이나 할 일 완료 상태를 바꾸지 않는다. 일시정지 구간은 실제 시간에서 제외한다.
- 최신 로컬 UI는 실제 한국 날짜로 기록하고, 공개 버전의 기존 화면은 선택 날짜의 이력을 표시하는 기존 동작을 유지한다. 공개 master에는 대시보드 개편이 아직 없어 공통 목록 실행 컴포넌트와 수행 기록 조회를 적용했다. 다른 로컬 개편 작업은 함께 배포하지 않는다.

검증: 독립 브라우저 출처에서 두 할 일로 시작, 중복 시작 차단, 일시정지, 새로고침 후 일시정지 유지, 휴식 전환, 종료, 다른 작업 시작, 수행 기록 조회, 종료 시간 재접속 유지, 완료 후 시작 버튼 숨김을 확인했다. 대시보드에서 작업 시작 목록과 다음 일정이 사라지는 것도 확인했다. 390px 화면에서 시작 버튼이 화면 안에 배치되는지 확인했다.
