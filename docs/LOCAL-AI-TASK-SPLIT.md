# 로컬 AI로 할 일 나누기

하루계획에서 **추가** 또는 Enter를 누르면 이 PC의 Ollama `qwen3:4b-instruct-2507-q4_K_M`가 입력을 의미 단위로 분석한다. 한 개의 단순 행동은 확인창 없이 저장하고, 여러 개면 제목 수정·항목 제외가 가능한 확인창을 거쳐 일괄 추가한다. 별도의 AI 버튼은 없다. 한 개의 짧은 할 일은 원래 제목을 유지하며, 120자를 넘는 단일 원문은 AI 제목과 함께 상세 메모에 보관한다.

- 원문: 최대 2,000자. 나눈 결과: 최대 32개, 제목별 120자.
- 여러 할 일은 확인 전에는 목록에 저장하지 않는다. 한 개는 분석 후 바로 저장한다. 취소·연결 실패·중복 오류가 나면 원문을 유지한다.
- 시간·중요도는 자동 추정하지 않는다. 명시된 조건은 제목에 남기고, 실제 일정은 기존 수정창에서 설정한다.
- 같은 날짜에 같은 제목으로 남아 있는 할 일은 중복 추가하지 않는다.
- 나누는 중에는 중단할 수 있다. 화면이나 계정이 바뀌면 해당 요청을 취소한다.

## 실행 조건

Ollama가 `http://127.0.0.1:11434`에서 실행 중이고 `qwen3:4b-instruct-2507-q4_K_M`가 설치돼 있어야 한다. 모델 확인은 `GET /api/tags`로 할 수 있다. 별도 API 키나 클라우드 호출은 사용하지 않는다.

로컬 주소에서는 Ollama를 직접 사용한다. 배포 앱에서는 로그인 후 Tailscale Funnel 뒤의 인증용 API로 같은 PC 모델을 사용한다. Ollama 원본 포트는 외부에 공개하지 않는다. 운영 절차는 `PC-OLLAMA-OPERATIONS.md`를 참고한다.

## 검증

- `npm.cmd test`: 분리 응답 검증, 원자적 일괄 추가, 중복·ID·분류 오류, 잘린 AI 응답, 외부 호스트 차단.
- `tests/local-ai-browser.tsx.template`: 임시 `app/local-ai-qa/page.tsx`로 복사해 별도 `localhost:3201`에서 실행하는 실제 Qwen 회귀 검사. 기존 계획·로그인이 있는 저장소는 거부하고 원본 보관 후 합성 데이터만 사용한다. 검사 후 Restore storage를 누르고 임시 경로를 제거한다.
- 실제 Qwen 예문과 브라우저에서 결과 수정·제외·일괄 저장·새로고침 유지·중복 거부·취소 시 원문 보존을 확인했다.

JSON 구조와 길이는 코드가 검증하지만 의미 분리는 모델이 틀릴 수 있으므로 사용자 확인 단계를 유지한다.

## 의미 분리 회귀 방지

기존 모델이 반복 수식어를 가진 여러 행동을 하나로 반환하는 문제를 재현하고, PC에 설치된 Instruct 모델로 교체했다. 여러 행동의 연결어 또는 줄바꿈이 있는 원문은 모델이 한 항목을 반환해도 자동 저장하지 않고 확인창을 띄운다. 이 감지는 분리 자체를 수행하지 않는다.

`node scripts/verify-ollama-split.mjs`는 실제 PC 모델로 신고 문장, 일반 복합 행동, 단일 행동과 동일 행동의 여러 대상을 검증한다.
