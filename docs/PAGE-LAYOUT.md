# 공통 페이지 레이아웃

페이지별 너비 제한과 제목 높이를 각각 관리하면서 본문 경계와 시작점이 달라졌다. 최신 로컬 UI의 하루계획·목표추적·하루점검·환경설정에 같은 `WorkspaceHeader`와 `oddk-pageBody`를 적용했다. 공개 버전의 기존 보기에도 같은 틀을 적용하며 날짜 선택·주 이동은 본문 도구 영역으로 옮겼다.

- 전체 프레임: 최대 1600px, 가운데 정렬. 데스크톱 좌우 40px/상단 32px.
- 제목: 24px, 공통 제목 영역 최소 72px, 본문까지 24px. 테마 버튼은 제목 오른쪽.
- 900px 이하: 좌우 24px/상단 24px. 640px 이하: 좌우 16px/제목 영역 최소 88px. 긴 설명은 잘리지 않고 늘어난다.
- 스크롤바 공간을 확보해 페이지 높이에 따른 가로 정렬 이동을 방지한다.
- 최신 로컬 UI의 하루점검 840px·환경설정 940px 별도 제한을 제거했다. 기능별 도구와 본문 내부의 배치는 유지한다.
- 공개 버전의 긴 제목은 메뉴와 연결되는 짧은 페이지 이름으로 통일했다. 선택한 날짜는 기존 날짜 필드와 주간 탐색에서 확인한다.

공통 배치는 `page-layout.css`, 제목 마크업은 `workspace-header.tsx`가 담당한다. 최신 로컬 토큰 시스템은 `styles/tokens.css`의 `--oddk-page-*`로 수치를 관리하고 구조 검사에서 페이지 틀의 중복 선언을 막는다. 공개 master에는 아직 로컬 UI 개편이 없으므로 같은 CSS의 기본값을 사용한다. 다른 로컬 기능 개편은 함께 배포하지 않는다.

실제 프로덕션 빌드에서 1920px 화면의 네 페이지가 본문 너비 1520px/제목 상단 32px/본문 시작 128px로 일치했다. 390px 화면에서는 네 페이지의 본문 너비와 제목·본문 시작점이 일치하고 가로 넘침이 없었다. 700px 및 900px 화면, 라이트·다크 테마도 확인했다.
