## 보완한 결함

- 연결 처리만 있고 누락돼 있던 수정 창의 ALPEN 이동 버튼을 추가했다. 명시적인 계획 날짜가 있어야 이동하며 저장한 날짜로 화면도 맞춘다. 날짜를 임의 배정하지 않는다.
- 팝업 양 끝에서 키보드 포커스가 문서 밖으로 나가던 현상을 실제 DOM focus로 확인하고 공통 순환 처리를 적용했다. 수정/재계획에서 재검증했다. 프로필/동기화 창도 같은 처리다.
- 작업 시간 입력 전 여유 비활성, 작업 해제 시 여유/시작 해제. 저장 전 검증은 기존 공통 규칙을 유지한다.
- 로컬127.0.0.1 origin의 개발 리소스 차단은 설치된 Next 문서에 따라 `allowedDevOrigins`에 루프백 호스트만 추가했다. 운영 API CORS는 바꾸지 않았다.
- 클라이언트 초기화 전에는 추가 입력을 비활성으로 두어 서버 HTML 단계의 기본 폼 제출을 방지했다.
- 추가 Enter 회귀 검사에서 ALPEN submit 버튼이 기본 제출로 선택되는 것을 발견했다. 이동 버튼을 일반 버튼으로 분리하고 명시적 클릭의 요청 안에서만 이동 의도를 전달한다. Enter 수정 저장은 목록 유지, ALPEN validation 실패 후 정상 Enter도 목록 유지, 명시적 키보드 ALPEN 버튼은 저장 날짜로 이동함을 재시험했다. 업무1개 유지 및 시험 전 상태 복원, 콘솔 오류0을 확인했다.

단위시험39개, lint/typecheck/정적 빌드 통과. 저위험 표시 변경을 구현 그대로 반복하는 시험은 추가하지 않았고 실제 UI 흐름으로 검증했다. 임시 QA HTML과 공간 채우기 자료는 삭제하여 배포하지 않는다.
