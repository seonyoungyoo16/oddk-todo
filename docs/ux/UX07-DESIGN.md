# UX07 가변 목표와 업무 세분화

상태: UX06 배포 게이트 이후 구현 시작. 이 문서는 아직 UX07 완료 증거가 아니다.

## 목표 모델과 호환

- 핵심 목표1 → ID가 있는 세부 목표 최대32 → 연결한 할 일의 3단계다. 세부 목표별 연결을 편집하고 완료 체크·흐린 글자로 실행 상태를 보여준다. 같은 업무의 여러 목표 연결은 같은 Task ID를 재사용한다.
- 원래 8×8 만다라트 문구·칸 위치·중복 연결·없는 업무의 ID까지 원문 백업과 이전 스냅샷에 보존한다. 트리는 같은 그룹의 중복 업무를 한 번 표시하고 이를 안내한다. 없는 업무 연결은 별도 복구 대상으로 표시한다.
- 전체 실행 업무 한도5000과 별도로 전체 활성 목표 연결도5000을 상한으로 둔다. 상한을 넘으면 잘라내지 않고 입력 보존·백업·한도 안내를 제공한다. 빈 기존 세부 목표도 이전 시 보존한다.
- 가변 트리가 새 편집 기준이 되므로 V5로 명시한다. 기존 V1~V4를 읽고 V5 이전 전 원문을 보존한다. V5가 저장된 계정에 이전 클라이언트의 쓰기는426으로 거부한다. UI만 먼저 공개하지 않는다.
- 현재 트리가8개 그룹/그룹당8개를 넘으면 만다라트 표로 자르지 않는다. 모든 내용을 보이는 트리를 유지하고 표의 제한을 안내한다. 보관한 원래 만다라트도 조회할 수 있게 한다.
- 세부 목표 삭제는 할 일을 삭제하지 않는다. 연결 해제 대상을 확인하고 실행 취소로 그룹·연결을 복구한다. Task 삭제·일괄 삭제도 새 목표 연결을 함께 처리한다.

## 업무 세분화와 시간

- 원본 업무를 유지하고 새 실행 업무마다 새 ID를 만든다. 원본과 연결한 같은 세부 목표로 이어주며 기존 날짜·메모·시간·완료는 임의로 변경하지 않는다. 새 업무 시간은 사용자가 정한다.
- 원본을 실행 업무로 유지할지 목표 요약으로 전환할지 명시적으로 선택한다. 요약으로 전환할 때만 실행 건수/시간 집계·시간표에서 제외하고 이를 미리보기와 목록에 표시한다. 시간 정보 자체는 보존한다.
- 요약/실행 시간의 중복 합산 여부를 미리보기로 확인한 후 적용한다. 원본이 실제 실행 업무라면 새 실행 업무와 함께 합산됨을 알린다. 자동으로 시간을 나누거나 줄이지 않는다.
- 기존 수정창·만다라트 초안·undo는 보존한다. 이전 연결 초안과 새 목표 구조가 다르면 백업과 비교 후 연결을 선택하며 오래된 초안을 조용히 폐기하거나 새 연결을 덮지 않는다.
