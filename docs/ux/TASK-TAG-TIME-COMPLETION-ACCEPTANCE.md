# 할 일 태그 추가와 표시 수정 확인

확인일: 2026-10-31 (Asia/Seoul)

## 반영 내용

- 수정 팝업에서 태그 이름을 입력하고 Enter 또는 태그 추가 버튼으로 선택한다.
- 기존 태그는 재사용하며 새 태그 정의와 업무 연결은 마지막 저장에서 함께 반영한다. 입력 후 추가 버튼 없이 저장해도 마지막 태그를 반영한다.
- 취소는 새 태그와 업무 변경을 저장하지 않는다. 닫기/초안 보관은 기존 편집 초안 동작을 따른다.
- 이름의 #, 공백, Unicode 정규화와 대소문자를 고려해 중복을 막는다. 이름 30자, 업무당 10개, 전체 100개 제한을 유지한다.
- 소요시간만 있는 업무는 목록에 소요 N분을 표시한다. 시작·종료 시각이 있는 업무는 기존 시각 범위를 유지한다. 시간이 없는 업무의 종일 표시는 유지한다.
- 목록과 목표추적의 완료 항목에서 취소선을 제거하고, 만다라트의 완료 V 아이콘을 제거했다. 완료 색상과 보조기술용 완료 설명, 일괄 작업용 선택 기능을 유지한다.

## 실제 브라우저 확인

기존 개발용 데이터와 분리된 `http://127.0.0.1:3271/oddk-todo/todo/`에서 정적 빌드를 실행했다. 로그인 없이 새 브라우저 출처에 검증용 업무를 생성했다.

| 동작 | 확인 결과 |
|---|---|
| 태그 업무 입력 후 Enter | 팝업이 닫히거나 업무가 조기 저장되지 않고 태그 1개 선택 |
| 같은 이름을 #·공백과 함께 다시 추가 | 새 정의 없이 1개 선택 유지 |
| 작업 25분 + 여유 5분 저장 | 시작 시각 없이 목록에 소요 30분 표시 |
| 새로고침 후 재편집 | 태그 선택과 작업/여유 시간 유지 |
| 새 태그와 시간 변경 후 취소 | 취소한 태그는 없고 기존 25+5분 유지 |
| 이름 31자 입력 | 길이 오류 표시, 팝업과 입력 유지 |
| 개인 입력 후 추가 없이 저장 | 태그 정의와 연결이 함께 저장 |
| 완료 항목 목록 | 취소선 없음, 기존 완료 색상 유지 |
| 완료 항목을 만다라트에 연결 | 제목 버튼의 체크 SVG 0개, 제목과 버튼의 text-decoration은 none, 완료 배경색 유지 |
| 390px 모바일 팝업 | 태그 입력 영역과 문서 가로 넘침 없음 |
| 콘솔 | 오류·경고 없음 |

앱의 백업 기능으로 실제 저장 JSON을 내려받아 태그 2개 연결, 총 30분/여유 5분/시작 시각 null, 완료 상태와 목표 연결을 대조했다. 취소한 태그가 없음을 확인했다.

검증 뒤 생성한 목표 연결, 태그 2개와 업무를 화면에서 정리했다. 임시 정적 서버는 종료했다. 개발 서버의 기존 업무와 계정 데이터는 수정하지 않았다.
