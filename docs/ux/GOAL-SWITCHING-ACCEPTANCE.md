# 목표별 만다라트와 자동 저장

목표 전환 선택창과 새 목표 추가 버튼을 제공한다. 목표 저장 버튼은 없으며 입력 직후 초안을 기기에 보관하고 400ms 후 유효한 내용을 계획에 자동 반영한다.
저장 전 다른 목표로 이동해도 목표별 초안은 유지되고 자동 저장을 이어간다. 저장 실패·충돌·삭제된 할 일 연결이 있으면 초안을 보관하고 사용자에게 표시한다.

## 데이터

- `goalTree.groups`가 모든 목표의 공통 연결 원본이다. 할 일·반복 일정의 기존 그룹 ID는 바꾸지 않는다.
- 선택적인 `goalBoards`는 핵심목표별 이름·그룹 ID·8×8 셀 배치를 보관한다. 새 빈 칸의 ID는 예약하고 실제 제목이나 연결이 생길 때 그룹을 만든다.
- 기존 단일 목표는 `default` 목표로 읽는다. 원래 만다라트와 이전 초안 원문은 보존한다. 기존 목표가 8×8을 넘으면 자르지 않는다.
- `goal-boards` 로컬 초안에는 `selectedId`와 목표 ID별 `drafts`를 보관한다. 기존 계정별 저장 범위를 그대로 사용한다.
- 목표 전환은 계획 데이터를 교체하지 않는다. 초기화는 선택한 목표의 내용과 연결만 비운다.
- 핵심목표 최대 32개, 전체 세부목표 32개·연결 5000개라는 기존 공통 한도와 요청 크기 한도를 검증한다. 한도를 넘는 입력은 초안에 남는다.
- 동기화는 기존 계획 JSON 경로를 사용한다. DB 스키마·인증·접근 권한 변경은 없다.

실제 브라우저 검증은 별도 루프백 출처의 합성 데이터로 진행한다. `tests/goal-boards-browser.tsx.template`은 그 준비·검사·정리 화면이다.
린트·타입 검사·프로덕션 빌드와 전체 단위 테스트 350개가 통과했다. 정적 배포 빌드에서도 초안 백업·자동 저장을 확인했다. 임시 검증 경로와 합성 데이터는 정리했다.
로그인한 두 실제 기기 사이의 왕복 동기화는 이 로컬 검증 결과에 포함하지 않는다.
