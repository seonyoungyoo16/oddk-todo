# 전체 작업 마지막 사용자 인수 목록

상태: 보류 목록. 지금 사용자에게 실행을 요청하는 문서가 아니다. UX00~UX13에서 가능한 구현·자동/브라우저 QA·단계별 배포 검증을 끝낸 뒤 한 번에 안내한다. 사람이나 실제 단말이 필요한 시험을 소프트웨어 모사 결과로 완료 표시하지 않는다.

| ID | 마지막에 확인할 내용 | 완료 판단 | 현재 상태 |
|---|---|---|---|
| H01 | 실제 Google 계정 로그인/로그아웃 | 제공자 로고·이름/내 정보·동기화가 실제 계정에서 정상이며 로그아웃 후 SSO로 복귀 | 사용자 별도 검증 대기 |
| H02 | 실제 GitHub 계정 로그인/로그아웃 | 제공자 정보가 맞고 해당 계정의 계획만 표시. OAuth 미실행을 이유로 버튼을 비활성화하지 않음 | 사용자 별도 검증 대기 |
| H03 | 실제 두 기기에서 같은 계정 동기화 | 시험용 할 일·목표 변경이 다른 기기에 반영되고 다른 계정에는 보이지 않음. 미전송 변경/충돌도 보존 | 실제 기기 인수 대기 |
| H04 | 브라우저/OS 알림 권한 허용·거부·철회 | 내 정보에서 명시적으로 켜기, 거부/설정 철회 안내와 끄기 상태 일치 | 물리 권한 미요청 |
| H05 | 앱을 배경으로 보내거나 탭을 닫은 뒤 실물 알림 수신·클릭 | 시작/사전 알림 표시와 클릭 날짜 이동. 완료·삭제·시간 변경·로그아웃/원격 해제 후 오래된 제목 비노출 확인 | 실제 단말 전달 미실행 |
| H06 | iPhone/iPad를 사용할 경우 홈 화면 설치 | standalone 실행·아이콘·권한 설정/수신 확인. 지원하지 않는 OS/브라우저는 환경과 이유 기록 | 해당 기기 있을 때 확인 |
| H07 | 실제 휴대전화 터치·보조기술 | 작은 화면의 일정 조작·팝업·키보드·읽기 순서/초점과 완료 상태를 구분 가능 | UX13에서 가능한 범위 먼저 검증 |
| H08 | 처음 사용하는 다른 사람의 사용성 | 용어 설명 없이 할 일 등록→날짜·시간 배치→목표 연결→복구 과제 수행, 도움 요청·오해 기록 | 독립 사용자 시험 대기 |

- 테스트 전에 필요한 계획/초안은 백업하고 별도 시험 항목을 사용한다. 기존 업무를 지우며 시험하지 않는다.
- 공급자 수락(sent), 브라우저 표시 확인(ACK), 사람이 실제 본 알림은 다른 증거다. 무조건 전달·초 단위 정시·정확히 한 번을 보장한다고 표시하지 않는다.
- 물리 알림은 OS/브라우저·네트워크·절전 상태의 영향을 받는다. 운영 예약 주기와 실제 관측 시각을 함께 기록하고 실패 시 환경을 남긴다.
- 앞으로 UX11~UX13에서 추가되는 사람 전용 항목만 이 목록에 이어 적는다. 유료 계약·계정 보안 수단의 변경이 실제로 필요해질 때에만 구체적 이유와 준비된 결과를 함께 안내한다.

기록 양식: `ID / 기기·OS·브라우저 / 대상 배포 SHA / 재현 순서 / 기대값 / 관측값 / 증거 / 통과·실패·해당 없음 / 남은 조치`.
