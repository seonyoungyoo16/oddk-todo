# 오늘의 명언 — 외부 API 연동

사용자가 지정한 [korean-advice-open-api](https://github.com/gwongibeom/korean-advice-open-api)의 실제 응답을 표시한다. 고정 명언 목록은 사용하지 않는다. 이 API는 개발 전용 필터를 제공하지 않으므로, 사용자가 선택한 대로 일반 명언을 사용한다.

## API 계약

- GET https://korean-advice-open-api.vercel.app/api/advice
- 응답: author, authorProfile, message 문자열. API에서 받은 저자·소개·본문을 그대로 텍스트로 렌더링한다. 책 제목이나 검증되지 않은 원전 정보를 덧붙이지 않는다.
- API 키 없음. 요청 본문 없음. credentials=omit, referrerPolicy=no-referrer, cache=no-store. 계획·계정·사용자 데이터를 보내지 않는다.
- 2026-10-31 실제 요청에서 HTTP 200과 Access-Control-Allow-Origin: *를 확인했다. 저장소의 api/advice.ts 및 README와 응답 계약을 대조했다.
- 8초 제한, HTTP/JSON/길이 검증. 실패 응답을 캐시에 저장하지 않는다. 같은 문장이 이전 날짜에 저장되어 있으면 최대 3회 안에서 다른 응답을 시도하고, 계속 같으면 이전 문장과 실패 상태를 보여준다. 무한 재요청은 하지 않는다.

## 하루 유지와 장애 처리

- 부모 화면의 실제 한국 날짜를 사용한다. 선택한 계획 날짜를 바꾸어도 명언 날짜가 바뀌지 않는다.
- 해당 브라우저·출처(origin)의 localStorage에 버전·한국 날짜·API 응답 하나를 저장한다. 같은 날의 새로고침은 저장된 실제 응답을 재사용한다. 다른 기기까지 동일한 명언을 강제하는 서버 캐시는 없다.
- 같은 날짜의 동시 마운트와 React 개발 모드의 중복 효과는 진행 중인 요청을 공유한다.
- 날짜가 바뀌면 새 API 응답을 요청한다. 실패하면 마지막으로 받은 명언의 실제 날짜와 ‘이전 문장’ 안내, 재시도 버튼을 표시한다. 저장된 응답도 없으면 실패 안내와 재시도만 표시한다. 고정 문장으로 대체하지 않는다.
- 저장소가 차단되면 메모리에서 당일 응답을 유지하고, 새로고침 시 바뀔 수 있음을 표시한다. 늦게 도착한 이전 날짜의 응답은 더 최신 캐시를 덮지 않는다.
- 서버 렌더 시에는 브라우저 저장소를 읽지 않는다. 날짜가 준비되고 보이는 화면에서만 API 요청을 시작한다.

## 표시 위치와 출처

- 최신 로컬 개편 작업본: 대시보드 상단.
- 현재 공개 버전: 대시보드 메뉴가 아직 없으므로 하루 범위의 계획 개요 상단. 목표·주간·전체 목록에서는 숨긴다.
- UI에 제공자 저장소 링크를 ‘한국어 명언 API’로 명확하게 표시한다. 제공자 코드를 복제·수정하거나 자체 배포하지 않고 공개 엔드포인트만 호출한다.
- 제공자의 [라이선스](https://github.com/gwongibeom/korean-advice-open-api/blob/main/LICENSE)는 출처 표시를 요구하며, 상업적 사용은 제공자와 사전 협의가 필요하다고 명시한다.

## 검증

단위 테스트는 외부 네트워크를 모킹하여 응답 검증, 정확한 엔드포인트, 일일 재사용/재접속, 동시 호출, 한국 자정, 중복 제한, HTTP·형식·시간 초과, 재시도, 저장 차단, 탭 경합과 날짜 역전을 검사한다. 브라우저에서는 실제 API 응답과 표시 본문을 대조하고, 새로고침 재사용과 장애 시 이전 API 응답/재시도를 별도로 확인한다.
