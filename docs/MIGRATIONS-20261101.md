# 운영 account migration 식별자

이 SQL5개는 운영에 이미 적용됐습니다. 기존 로컬 초안과 실제 운영의 version prefix가 달라 이번 통합 소스의 이름을 운영 history와 맞췄습니다. SQL 본문은 바꾸지 않았으며 이 정합화 때문에 다시 실행하거나 운영 history를 수정하지 않습니다.

| 기존 초안 version | 운영·통합 소스 version |
| --- | --- |
| 20261101004248 | 20261101004808 |
| 20261101005029 | 20261101005038 |
| 20261101005442 | 20261101005459 |
| 20261101010456 | 20261101010505 |
| 20261101011523 | 20261101011703 |

기존 초안은 원래 작업 경로에 보존합니다. 새 환경을 구성할 때는 통합 소스의 migration 순서를 사용하고, 기존 운영에는 현재 history와 본문을 확인한 후 필요한 신규 변경만 별도 배포합니다. 이 통합에서 신규 DB 정책/테이블을 추가하지 않았습니다.
